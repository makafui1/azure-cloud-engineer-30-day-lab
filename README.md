# Azure Cloud Engineer 30-Day Lab Projects

This repository contains 30 practical Azure projects created over 30 days to build deep hands-on experience while preparing for the Microsoft AZ-104 certification.

## Objective
- Build, configure, and deploy cloud infrastructure on Microsoft Azure
- Automate common tasks using Azure CLI and ARM templates
- Prepare for and pass the AZ-104 exam
- Gain experience to land a job as an Azure Cloud Engineer

## Topics Covered
- Azure Identity & Access Management (IAM)
- Virtual Machines, Scale Sets, Load Balancing
- Virtual Networks, NSGs, Peering
- Azure Storage (Blob, File), Backup & Recovery
- Azure Monitor, Alerts, Key Vault
- Governance, Policy, and Cost Management

## How to Use
Each folder under `weekX_...` contains:
- `README.md` with the day's objective
- CLI/ARM/Bicep scripts (where applicable)
- Screenshots and output logs

Final Project is a real-world multi-tier deployment using best practices.
